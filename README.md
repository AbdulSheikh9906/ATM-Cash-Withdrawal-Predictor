# 🏧 ATM Cash Withdrawal Predictor

This project is a smart ATM cash withdrawal prediction system built using **Random Forest**, leveraging **temporal (day, time)** and **weather-based** features to accurately forecast daily withdrawal amounts. The system also features a clean and interactive **Shiny Web Application** to visualize predictions.

---

## 📌 Features

- 📊 **Predicts ATM cash demand** using historical data
- ⏰ **Time-based & weather-based prediction**
- 🧠 **Random Forest Machine Learning model**
- 💻 **Interactive Shiny web dashboard**
- 📈 Helps in **optimizing ATM refilling operations**

---

## 🔧 Tech Stack

| Layer        | Tools / Languages                    |
|--------------|--------------------------------------|
| Machine Learning | Python, Scikit-learn, Pandas       |
| Data Handling | CSV / Tabular Data                  |
| Frontend / UI | R, Shiny (for web interface)        |
